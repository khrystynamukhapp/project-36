# Lviv Food Spots (MVP)

Mini project for Git workflow practice: branching, PR, code review, conflict resolution.

## Idea
Catalog of Lviv places (cafes/restaurants) with:
- category filter
- search by name

## Structure
- src/index.html
- src/style.css
- src/app.js
- docs/notes.md

## How to run
Open src/index.html in a browser.
